# Airevo storefront

Premium kitchen-appliance storefront built as a responsive static website.

## Current preview features
- Brand-led landing page and product/category navigation
- Shop Online section with category filters, search and sorting
- Product detail quick views and wishlist (browser-local)
- Basket with quantity updates and removal
- Checkout address and payment-preference form
- Enquiry popup and WhatsApp order/enquiry hand-off
- Responsive mobile navigation and floating WhatsApp assistance

## Before accepting live orders
The catalogue currently contains illustrative product names, images, specifications and sample prices. Replace them with Airevo-approved SKUs, actual product photos, prices, stock, warranty and delivery terms.

The checkout currently prepares an order request in WhatsApp. It does not create a merchant order record, collect payment, reserve stock, or issue order confirmations. Production e-commerce requires an order backend/database, a verified WhatsApp Business destination, shipping/tax rules and a payment gateway integration (for example Razorpay) with production credentials and webhook verification.

Update the social profile URLs, business email, telephone/WhatsApp destination, policies and service details before launch.
